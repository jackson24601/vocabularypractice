# WordNest

A simple web app that helps teachers create vocabulary practice sets for students.

## Teacher page

Teachers can:

- Name a vocabulary set
- Set a practice due date
- Enter an email address for student completion reports
- Add up to 10 terms and definitions

Sets are saved in the browser for now (`localStorage`) so the teacher flow can be used immediately while the student practice side is built next.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
